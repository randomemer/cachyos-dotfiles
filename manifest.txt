# Manifest of tracked config, relative to $HOME.
# Blank lines and #-comments are ignored.
#
# Two sections. The tag in column 1 decides how tools/link.sh treats the path:
#
#   link   Nothing but you and your editor writes this. Safe to symlink from
#          the repo into place; edits land in the repo automatically.
#   copy   A program owns this file and rewrites it on its own schedule.
#          Symlinking works today (verified) but is a standing bet on that
#          program's write strategy. Snapshot it with sync.sh instead.
